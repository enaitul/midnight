6. SDE INTERVIEW PREPARATION (8 QUESTIONS & ANSWERS)
----------------------------------------------------
Q1: How does Vite handle static asset imports like `import img from '../assets/img.png'`?
A: Vite processes the asset through its build pipeline. During development, it serves it
via an internal URL. During production (`vite build`), it hashes the file content into the
filename (e.g. `creator-EsWkYYWL.png`), places it in `dist/assets/`, and rewrites the
import in the JavaScript bundle to point to the hashed URL for immutable HTTP caching.

Q2: What is the benefit of using CSS Custom Properties (CSS variables) for theme switching?
A: CSS variables allow dynamic theme changes in real time by simply modifying an attribute
on the root document (e.g., `document.documentElement.dataset.theme = 'dark'`). The browser
re-evaluates all dependent CSS rules instantly without requiring a page reload, re-rendering
React component trees, or loading alternate stylesheets.

Q3: Why should public portfolio or external links use `rel="noreferrer"` alongside `target="_blank"`?
A: Opening a new tab with `target="_blank"` without `rel="noreferrer"` (or `noopener`) allows the
target page to access the original page's `window.opener` object, creating a security vulnerability
(tabnabbing). It also leaks the referring site URL in the HTTP `Referer` header.

Q4: How do you achieve responsive images without layout shift (CLS - Cumulative Layout Shift)?
A: By setting explicit aspect ratios via CSS (`aspect-ratio: 4/5; width: 100%; object-fit: cover;`),
the browser reserves the correct dimensional space on the page before the image bytes finish downloading,
preventing surrounding text from jumping.

Q5: In React Router v6+, what is the difference between `<Link>` and standard `<a>` tags?
A: Standard `<a>` tags perform a full browser HTTP reload of the page. `<Link>` intercepts the click
event, prevents the default browser reload, and updates the URL via the HTML5 History API, allowing
React Router to swap components client-side in milliseconds without losing application state.

Q6: Why is typography choice critical for long-form reading applications?
A: Serifs (such as Georgia, Lora, or Playfair Display) provide horizontal visual flow that guides
the eye across extended lines of text. Combined with generous line-height (`1.7` to `1.9`) and
restrained maximum line widths (`60ch` to `70ch`), it reduces reader eye fatigue.

Q7: What is the role of an "empty state" or informative landing page in user onboarding?
A: It provides essential context and intent before a user creates an account or writes.
Explaining platform norms on dedicated about pages aligns user expectations and fosters a culture
of thoughtful writing rather than impulsive posting.

Q8: How do you ensure static pages do not bloat application bundle size?
A: Keep static components lightweight by relying on native HTML elements, CSS variables, and
reusable shared stylesheets rather than pulling in external heavy UI component libraries or animation engines.
